# Manuels

Guides d'utilisation des outils Rewake, écrits pour les équipes qui s'en
servent au quotidien (pas pour les développeurs : le reste de cette
documentation est technique).

| Manuel | Pour qui | Contenu |
|---|---|---|
| [Réception produits](./reception-produits.md) | Équipe opérations | Réceptionner une reprise produit par produit dans l'intranet (`app.rewake.fr`) : photos, n° de série, marque et modèle, mesures, état, accessoires ; chaque produit complet part dans Airtable, puis fin de réception. |

Les images de chaque manuel sont dans `docs/manuals/images/<manuel>/` ; tant
qu'une capture n'est pas fournie, une image provisoire grise indique son
numéro et ce qu'elle doit montrer. Une capture marquée « ancienne interface »
montre une version précédente de l'écran : le texte fait foi.
