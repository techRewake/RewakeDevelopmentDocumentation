Rewake API

The back-end API for Rewake – internal tooling (used by the app.rewake.fr/sav.rewake.fr intranet apps) and external integrations (HelloPro, Machinio), served at api.rewake.fr.

This documentation set is new (see Development for why and what’s still missing); the API and its endpoints existed and were in production well before it.

Reference

  • Routes – every endpoint, its access rules, and example responses.

  • Authentification – the token/origin model behind those access rules.

  • Architecture – how the project fits together, including the Celery/Redis queued-script path.

  • Operations – configuration, deployment, and logging.

  • Development – environment setup, Airtable/Shopify dev credentials, and the scripts/ dev tooling.

  • Scripts – what each registered script does, on demand or scheduled.
