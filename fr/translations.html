Traductions et publication

La documentation est publiée sous la forme de deux sites Sphinx statiques, dans /en/ et /fr/ du dépôt public RewakeDevelopmentDocumentation. La page d’accueil renvoie vers les deux langues. Le site généré contient les pages HTML et les ressources nécessaires à leur affichage.

Les traductions utilisent les catalogues gettext de Sphinx dans docs/locale/<language>/. Les pages sources sont actuellement en anglais et en français. Chaque catalogue traduit les pages écrites dans l’autre langue ; tant qu’une traduction n’est pas terminée, le texte source reste affiché.

Pour actualiser les modèles de traduction et créer ou mettre à jour les catalogues français et anglais :

make docs-gettext
make docs-catalogs

Translate the msgstr values in the relevant docs/locale/<language>/ catalogs while preserving Sphinx roles, references, code, and markup. Build both languages locally with:

make docs       # English and French

The Build and publish documentation GitHub Actions workflow builds both languages on every push to main and pushes the generated site to the gh-pages branch using the repository’s GITHUB_TOKEN. In the GitHub repository settings, configure Pages to deploy from the gh-pages branch root. The workflow can also be started manually from the Actions tab.
